# V4 제품 범위와 확정 결정

## 목표

사용자는 지금 가진 재료로 만들 수 있는 요리를 빠르게 찾고, 부족한 재료가 있는 요리도 분리해서 탐색하며, 오늘 만들 메뉴를 잊지 않고 모아 볼 수 있어야 한다. 재료함의 조작은 실제 보유 상태를 사용자가 직접 관리한다.

## 검색

검색은 공개된 `PUBLISHED` 레시피만 대상으로 한다. 검색어는 레시피 제목과 레시피 원문 재료의 표시명에서 대소문자·공백 차이를 무시하고 부분 일치로 찾는다. 원문 재료를 canonical owned item 이름으로 바꾸거나, AI·문자열 유사도로 검색 대상을 추론하지 않는다.

검색 탭은 서로 다른 범위다.

| 탭 | 검색 범위 | 결과 의미 |
| --- | --- | --- |
| `지금 있는 걸로` | 현재 사용자의 모든 필수 Requirement가 충족된 `PUBLISHED` 레시피 | 지금 바로 만들 수 있는 결과만 보인다. |
| `재료 추가해서` | 현재 사용자의 필수 Requirement 중 하나 이상이 부족한 `PUBLISHED` 레시피 | 재료를 추가하면 만들 수 있는 결과만 보인다. |

두 검색 탭은 배타적이다. 같은 레시피가 `지금 있는 걸로`와 `재료 추가해서` 검색 결과에 동시에 들어가지 않는다. 검색어가 비어 있으면 검색 결과를 요청하지 않고 검색 전 안내 상태를 보인다.

각 탭의 결과 정렬은 다음 순서로 고정한다.

1. `지금 있는 걸로`는 모두 만들 수 있는 결과이므로 제목 일치가 재료명 일치보다 먼저, 이후 제목 가나다순·recipe ID순으로 정렬한다.
2. `재료 추가해서`는 부족한 Requirement 수(`missingCount`)가 적은 레시피를 먼저 둔다. 같은 부족 수 안에서는 제목 일치, 재료명 일치, 제목 가나다순·recipe ID순을 적용한다.

## 오늘 먹을 메뉴

레시피 상세에서 사용자는 `오늘 먹을 메뉴로 담기`를 눌러 메뉴를 보관한다. 같은 레시피는 같은 날 한 번만 담을 수 있다. 다시 누르거나 홈 카드의 제거 버튼을 누르면 오늘 메뉴에서 빠진다.

- 사용자별·한국 표준시(KST) 날짜별 목록이다.
- 개수 제한은 없다.
- 최근에 담은 메뉴가 위에 온다.
- 목록은 다음 KST 자정에 자동으로 사라진다. 다음 날로 넘기거나 이력을 보관하지 않는다.
- `PUBLISHED`가 아니게 된 레시피는 읽을 때 조용히 숨긴다. 과거 Redis 목록을 일괄 수정하지 않는다.
- Redis를 사용할 수 없으면 홈의 오늘 메뉴 섹션을 조용히 숨긴다. 추천과 다른 홈 기능은 계속 동작한다. 담기/빼기 요청은 성공한 것처럼 보이게 하지 않고 재시도 가능한 오류로 처리한다.

오늘 메뉴는 조리 완료나 재료 소비를 뜻하지 않는다. 메뉴를 담거나 빼도 보유 재료는 바뀌지 않는다.

## 재료함과 레시피 상세의 빠른 조작

V3의 Ingredient group/selectable owned item 정책은 그대로 유지한다. 재료함은 선택 가능한 owned item 하나의 추가·삭제만 수행하며, group은 선택 대상이 아니다.

레시피 상세에서 사용자가 재료 행을 통해 재료함을 바꿀 수 있다.

- 부족한 필수 요구는 그 레시피에서 허용된 owned item 후보만 보여 준다. 후보를 하나 고르면 그 owned item을 재료함에 추가한다.
- 전역 대체 관계나 새로운 추천 규칙을 만들지 않는다. 기존 V3의 exact item, recipe-local accepted owned item, 기존 option의 허용 후보 밖의 재료는 제안하지 않는다.
- 현재 보유한 재료를 제거하려 할 때만 `다 먹었나요?` 확인을 표시한다. 사용자가 `다 먹었어요`를 확정했을 때만 실제 삭제한다.
- 레시피를 열거나 조리 단계를 보았다는 이유로 자동 차감하지 않는다.
- 추가·삭제 성공 후 상세의 충족/부족 상태를 즉시 다시 계산해 표시한다. 홈·추천은 다음 진입 또는 명시적 새로고침에서 갱신하면 된다.

## 부족 재료의 외부 구매 탐색

쿠팡파트너스 출시 전까지는 부족한 필수 재료의 `쿠팡에서 보기` 진입점을 노출하지 않는다. 제휴 기능 출시 시 아래 외부 구매 탐색 흐름을 다시 활성화한다.

- URL은 `https://www.coupang.com/np/search?q={URL-encoded requiredName}` 형식의 일반 검색 URL이다.
- 표시하는 재료명은 현재 부족한 Requirement의 `requiredName`이다.
- 상품·가격·재고·추천 상품을 앱에서 조회하거나 표시하지 않는다.
- 파트너스 링크, 추적 파라미터, 수익·전환 추적을 넣지 않는다.
- 쿠팡으로 이동하거나 앱으로 돌아와도 재료함을 자동으로 추가·삭제하지 않는다.

## 신규 가입 온보딩과 약관

V4부터 새로 가입한 사용자만 아래 순서를 따른다. 기존 사용자는 이미 약관과 온보딩을 완료한 것으로 간주하여 이 흐름을 다시 보지 않는다.

1. 로그인 성공 후 필수 약관 동의
2. 자취생에게 흔한 재료의 빠른 선택 또는 전체 재료 목록에서 직접 선택
3. 선택한 재료를 한 번에 저장하고 홈으로 이동

필수 동의 항목은 서비스 이용약관, 개인정보 수집·이용, 만 14세 이상 확인이다. 세 항목 모두 동의해야 다음으로 갈 수 있다. 문서 보기는 공개된 Notion 페이지를 외부로 연다. `전체 동의`는 세 필수 항목을 모두 선택/해제한다.

빠른 선택 화면은 카탈로그 순서로 아래 14개를 추천하고 미리 체크한다. 이 목록은 자취생에게 보유 가능성이 높고, 현재 데이터에서 바로 만들 수 있는 레시피를 열어 주는 기본 조합이다.

`진간장`, `계란`, `고추장`, `밥`, `물`, `식용유`, `참기름`, `참깨`, `양파`, `대파`, `김치`, `다진 마늘`, `소금`, `설탕`

화면에 미리 체크되어 보여도 사용자가 완료하기 전에는 보유 재료가 아니다. 사용자는 빠른 선택 카드 안에서 추천 선택을 바꾼 뒤 하나 이상을 선택해 완료한다. 초기 온보딩에서는 전체 목록 직접 선택과 재료 없이 둘러보기 경로를 제공하지 않는다.
