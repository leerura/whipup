# V4 UX와 화면 상태

모든 화면의 최종 시각 디자인은 [V4 개선·신규 기능 시안](https://www.figma.com/design/duKRNE3kpKMhItEbtq9WXz/%EB%83%89%EC%9E%A5%EA%B3%A0-%ED%84%B8%EC%9D%B4-%F0%9F%8D%9A?node-id=430-1492)을 따른다. 이 문서는 화면 간 동작과 예외 상태를 고정한다.

## 검색 (V4-S)

- 검색은 추천 목록 화면 안에서 수행한다. 검색 중에도 `내 재료 n개 기준`, 목록 제목, 검색창과 범위 탭은 유지한다.
- `지금 있는 걸로`와 `재료 추가해서`는 서로 다른 서버 검색 범위다. 탭을 바꾸면 같은 입력어로 새 검색을 요청한다.
- 검색 전에는 탐색을 유도하는 기본 상태를 보인다. 결과 없음은 API 오류와 구분하고, 검색어와 맞는 레시피가 없다는 안내를 보인다.
- `지금 있는 걸로`에는 모든 필수 Requirement가 충족된 결과만, `재료 추가해서`에는 하나 이상 부족한 결과만 보인다. 두 탭의 결과는 겹치지 않는다.
- 네트워크/서버 실패만 재시도 UI를 보인다.

## 오늘 먹을 메뉴 (V4-T)

- 홈에서 항목이 하나 이상일 때만 `오늘, 뭐 먹을까요?` 섹션을 보인다. 빈 상태의 회색 자리표시는 만들지 않는다.
- 카드 순서는 최근에 담은 순서다. 카드를 누르면 상세로, 제거 아이콘을 누르면 즉시 오늘 메뉴에서만 제거한다.
- 상세의 `오늘 먹을 메뉴로 담기`는 성공 후 담긴 상태와 `빼기` 동작으로 바뀐다. 다시 들어와도 API 상태를 기준으로 표시한다.
- 홈에서 연 상세에서 담기·빼기한 뒤 뒤로 돌아오면, 홈은 오늘 메뉴를 다시 읽어 즉시 최신 목록을 보인다.
- Redis 장애로 목록을 읽지 못하면 섹션을 숨긴다. 담기/빼기 실패는 짧은 재시도 안내만 보이고, 성공 상태로 전환하지 않는다.

## 재료함 (V4-I)

- 재료함은 보유/미보유를 분리한 두 목록이 아니라 하나의 catalog 목록이다. 각 selectable owned item의 체크 상태가 보유 여부다.
- group은 접기/펼치기와 탐색용 제목이다. 선택 버튼이 아니며 보유 수량을 표현하지 않는다.
- 검색과 필터는 표시만 좁힌다. V3의 group/variant 구조나 보유 정책을 바꾸지 않는다.
- item 추가·제거는 즉시 서버에 반영한다. 성공 후 짧은 되돌리기 토스트를 보일 수 있다. 되돌리기는 반대 API를 한 번 호출하는 동작이며, 실패하면 현재 서버 상태를 다시 읽는다.

## 레시피 상세 재료 조작과 쿠팡 (V4-Q, V4-F)

- 부족 Requirement의 `addableVariants`가 하나면 해당 item을 재료함에 담는 확인 동작을, 둘 이상이면 선택 시트를 보여 준다. 후보가 없으면 추가 control을 만들지 않는다.
- 보유 item을 제거하는 UI는 그 item을 가진 사용자가 명시적으로 누를 때만 `다 먹었나요?` 확인 시트를 연다. `아직 있어요`는 아무 변경 없이 닫는다.
- 쿠팡파트너스 출시 전에는 부족 Requirement의 `쿠팡에서 보기`를 노출하지 않는다. 제휴 기능 출시 시에만 외부 이동 흐름을 활성화한다.
- 쿠팡으로 이동한 결과로 재료를 자동 등록하거나 완료 토스트를 표시하지 않는다.

## 신규 사용자 온보딩과 약관 (V4-E, V4-G)

- 약관 동의는 로그인 직후, 재료 선택 전에 보인다. 세 필수 동의가 모두 선택되기 전에는 다음 CTA를 활성화하지 않는다.
- 약관/개인정보처리방침 `보기`는 public Notion URL을 외부로 연다. Notion 로그인 화면이나 앱 내부 WebView로 강제하지 않는다.
- 빠른 선택의 미리 체크된 재료는 아직 저장되지 않은 임시 선택이다. 사용자가 선택을 확인해 완료할 때만 온보딩이 끝난다.
- 초기 온보딩에는 `직접 고르기`와 `재료 없이 둘러보기` 진입점을 노출하지 않는다. 사용자는 빠른 선택 카드에서 필요한 항목만 선택하거나 해제한다.
- 빠른 선택은 카탈로그 순서로 `진간장`, `계란`, `고추장`, `밥`, `물`, `식용유`, `참기름`, `참깨`, `양파`, `대파`, `김치`, `다진 마늘`, `소금`, `설탕` 14개를 미리 선택해 보여 준다.
- 완료 후 홈으로 이동한다. 사용자가 나중에 재료를 모두 지워도 온보딩 화면으로 돌아가지 않는다.
