# V5 문서

V5는 V4를 이어 받아 앱 1.0.0 출시 이후의 개선을 다룬다. V4의 규칙(재료 카탈로그, Recipe Requirement, recipe-local accepted mapping, 추천 매칭, 게스트 계정, 레시피 데이터 반영 가이드)을 바꾸지 않는 영역은 [V4 문서](../v4/README.md)를 계속 따른다. 이 디렉터리의 문서와 V4가 다르면 V5가 우선한다.

## 범위

진행 순서는 아래 번호 순이며 1·2는 알림 출시의 선행 조건이다.

1. **레시피 상세에서 재료를 추가해도 추천 목록이 갱신되지 않는 문제 수정** — 앱 버그 수정(완료).
2. **레시피 파이프라인 개편** — 목표는 다양성을 먼저, 수율은 그 안에서. [파이프라인 개편](development/pipeline-overhaul.md)을 따른다.
3. **추천 알림** — 로컬 알림으로 시작한다. [추천 알림](product/notifications.md)을 따른다. 후보가 충분해진 뒤에 켠다.
4. **쿠팡 파트너스** — V4에서 범위 밖으로 둔 항목이다. V5에서 도입 여부와 방식을 결정한다.

위 항목은 구체적인 결정이 이 디렉터리 문서에 적히기 전에는 구현하지 않는다.

## 이번 버전에서 하지 않는 것

- **고기 재료 관리 방식 변경**(부위·용도형 항목 설계). 레시피가 더 쌓여 고기 표현이 충분히 모인 뒤 다시 논의한다. 그때까지는 V4의 현재 카탈로그와 매핑 규칙을 그대로 쓴다.
- 새로운 전역 재료 대체·호환 규칙.
