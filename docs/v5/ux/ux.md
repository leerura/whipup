# V5 UX와 화면 상태

V4 UX([V4 UX와 화면 상태](../../v4/ux/ux.md))를 바꾸지 않는 부분은 그대로 따른다. 이 문서는 V5에서 추가·변경하는 화면 간 동작만 고정한다.

## 추천 목록 새로고침 (V5-R)

- 추천 목록(검색 결과 포함)에서 연 레시피 상세에서 **재료를 실제로 담거나 뺀 뒤** 목록으로 돌아오면, 목록을 서버에서 다시 읽는다. 재료를 바꾸지 않고 돌아오면 다시 읽지 않는다.
- 다시 읽는 동안 **현재 목록을 그대로 보여 준다.** 목록을 비우거나 로딩 표시로 바꾸지 않는다. 다 읽으면 교체하며 **선택한 탭, 검색어, 스크롤 위치를 유지한다.** 목록이 짧아져 스크롤 위치를 넘으면 끝으로 맞춘다.
- 다시 읽기에 실패하면 현재 목록을 그대로 두고 오류 화면이나 안내를 새로 띄우지 않는다.
- `내 재료 n개 기준`의 개수도 함께 갱신한다.
- 다시 읽은 뒤 누른 레시피가 목록(또는 탭)에서 사라질 수 있다. 서버 상태를 그대로 보이며 위치를 보정하지 않는다. 두 탭의 결과는 서로 겹치지 않는다는 V4 규칙은 그대로다.
- 뒤로 가기 버튼과 스와이프 뒤로 가기는 같게 동작한다.
- 담기가 이미 보유 중이어서(409) 화면이 서버 상태보다 오래된 경우도 재료가 바뀐 것으로 보고 목록을 다시 읽는다.
