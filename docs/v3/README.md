# V3 문서

V3의 제품·도메인·UX 결정은 이 디렉터리를 기준으로 한다. V3 작업자는 먼저 이 문서를 읽고, 여기서 확정하지 않은 내용을 임의로 결정하지 않는다.

V2 문서는 이전 동작과 데이터 구조를 파악할 때만 참고한다. V2 결정이 V3 문서와 다르면 V3 결정을 따른다. 구현 세부를 정할 때 기존 코드와 기술 제약은 별도로 확인하되, V3에 없는 제품 규칙을 V2 문서에서 자동으로 가져오지 않는다.

## 예시 해석

V3 문서의 재료명과 사례는 원칙을 설명하는 예시이며, 허용되는 재료의 전체 목록이나 새 재료를 자동 분류하는 패턴이 아니다. 에이전트는 예시를 그대로 복사하거나 유사성만으로 규칙을 확장하지 말고, 문서에 적힌 판단 기준을 새 사례에 적용한다. 기준만으로 결론을 낼 수 없으면 새 결정을 만들지 말고 열린 질문으로 보고한다.

## 범위 메모

- 현재 문서는 재료 보유 단위, 레시피 요구, 요구 충족 판단의 제품·도메인 방향을 정한다.
- 데이터 파이프라인과 Gemini 무료 API 자동화의 재설계는 별도 논의로 미뤘다. V2 파이프라인 절차를 V3 요구사항으로 간주하지 않는다.
- `열린 결정`으로 표시한 항목은 구현 전에 Main Agent와 합의한다.
